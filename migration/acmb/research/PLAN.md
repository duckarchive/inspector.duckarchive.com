Every archive below has its own folder `migration/2026-08-22-<slug>-tomN/` (config.json, migration.sql, CSV inputs, README with per-class counts and what was left for editor review). Runs were done with `tools/execute.py` (queue in `tools/queue.txt`); dry-run then COMMIT each time.

## Classes (same letters as the т.4 migrations)
- **A** create справи the catalog cites but the DB lacks — title `Метрична книга. <church line>` (or `<label>. <church>` for non-metric kinds), tags from record kinds, years from the catalog.
- **B** add «метрична книга» + kind tags where the DB file has no MK tag.
- **C** fill empty title / years of existing files from the catalog.
- **D** fond year ranges from the summary header where the fond has none.
- **E** delete glued-code duplicates — only with an identical-title-and-span sibling (twins check at execution; the "suspicious codes" column is a heuristic, mostly false positives in big описи, e.g. ДАЧкО).
- **F** typo-fonds materialised in the DB (as ДАІФО `5941`) — per archive, found by comparing the catalog's fond list with DB fonds that have ≤ 3 files.
- **G** placeholder titles → catalog church names. Placeholder families seen: FamilySearch collection names (`Church records, Chernihiv N-N`, `Church Consistory Books, Chernivtsi`, `Church boards and churches, Kropyvnytsky`, `Церковні записи, … деканат (ф. N)`, `Колекція церковних метричних книг Закарпаття (ф. N)`, `Церковні записи, Подільська духовна консисторія (ф. N)`), generic `Метричні книги Православних церков[ <повіт>]`, bare `Метрична книга` / `Метрическая книга`, church-name-only (`Покровська`, ДАВіО), numeric (`N`, ДАТО) and empty. **Not** placeholders: rabbinate series (`Метрична книга євреїв м. Прилуки. Смерть`), ДАДнО ЗАГС books (`Книга регистрации актов гражданского состояния…`), ДАВоО's descriptive titles (`Метрична книга запису народжень, шлюбів та смерті …`).
- **H** year ranges: apply the catalog where the DB holds only the start year or a strict sub-range (ДАЖО: 672 of 793; ДАЧкО 402; ДАЖО b1 pattern `1802` vs `1802–1807`). Skip catalog typos (span > 60 years) and disjoint/shifted ones → editor review.
- **P** partially loaded описи (catalog cites far more справи than the DB holds): ДАХО Ф. 40 оп. 105/109/110/112/113 (1 347 books), ДАЧгО Ф. 1530 оп. 2 / Ф. 679 оп. 15–18 (~1 000), ДАТО (117), ДАЖО (91). These are **A** at scale; create them, they are real books.

## Checks at execution time (per archive, before generating SQL)
- Re-run `tools/run.py` for the archive (fresh DB snapshot) and re-read its `.md`.
- Catalog typos: fond numbers absent from the DB with ≤ 3 refs (→ map or drop), справа codes ≥ 5 digits in описи whose DB max is 4 digits (glued: ДАХО `126541864` = `1265а`+`1864`, ДАЧгО `127291`, `14020`), `спр. Nь`-style suffixes, `оп. 614` (ДАХО, 1 ref).
- Dedupe A against files that exist under an uppercase/letter variant of the code.
- G: apply only to titles matching the archive's placeholder family; never to rabbinate/ЗАГС/descriptive titles.
- H: only `DB ⊂ catalog` cases; list the rest in the archive README for editor review.
- Guards as in `migration/2026-08-22-tom4-dajfo-daluo-daoo-dapo/generate.py` (dry-run with ROLLBACK, then COMMIT).

## Known parser limits (accepted)
- Years and record kinds are the catalog's union per справа; a справа cited under several blocks (shared book) gets the first block's church line as title.
- `спр. A, B, C` lists are expanded; a 4-digit element in 1600–1950 directly followed by `:` or `–YYYY:` is treated as the next label's year, not a справа.
